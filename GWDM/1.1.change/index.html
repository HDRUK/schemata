    1.1

    Changes from 1.0 -> 1.1

    Added

    • accessibility.usage.resourceCreator.gatewayId (optional): Identifier on the gateway
    • accessibility.usage.resourceCreator.name: Name of the organisation
    • accessibility.usage.resourceCreator.rorId (optional): The Research Organization Registry (ROR) for the organisation, if applicable
    • coverage.anthropometric (optional): Cohort description: Height, Weight, Waist circumference, Hip circumference, Blood pressure
    • coverage.biologicalsamples (optional): Cohort description: Blood, Saliva, Urine, Other
    • coverage.gender (optional): Cohort description: Male, Female, Other
    • coverage.lifestyle (optional): Cohort lifestyle habits: Smoking, Physical activity, Dietary habits, Alcohol
    • coverage.physical (optional): Cohort description: Cardiovascular, Respiratory, Musculoskeletal, Hearing and Vision, Reproductive
    • coverage.psychological (optional): Cohort description: Mental health, Cognitive function
    • coverage.socioeconomic (optional): Cohort description: Occupation, Family circumstances, Housing, Education, Ethnic group, Marital status, Social support
    • required.version: Dataset metadata version
    • summary.datasetSubType (optional): Placeholder for dataset sub-type
    • summary.populationSize (optional): Summary population size of the cohort
    • summary.publisher.gatewayId (optional): Identifier on the gateway
    • summary.publisher.name: Name of the organisation
    • summary.publisher.rorId (optional): The Research Organization Registry (ROR) for the organisation, if applicable
    • tissuesSampleCollection (optional): metedata for tissue samples
    • tissuesSampleCollection.accessConditions (optional): Access conditions for the tissue sample collection
    • tissuesSampleCollection.collectionType (optional): The type of the sample collection. Can be several values MIABIS-2.0-16
    • tissuesSampleCollection.dataCategories (optional): The type of data that is associated with the samples in the study. Can be several values MIABIS-2.0-13
    • tissuesSampleCollection.disease (optional): Disease associated with the tissue sample collection
    • tissuesSampleCollection.id (optional): ID of the tissue sample collection
    • tissuesSampleCollection.materialType (optional): The biospecimen saved from a biological entity for propagation e.g. testing, diagnostics, treatment or research purposes. Can be several values MIABIS-2.0-14
    • tissuesSampleCollection.sampleAgeRange (optional): Age range of the tissue sample collection
    • tissuesSampleCollection.storageTemperature (optional): Storage temperature of the tissue sample collection
    • tissuesSampleCollection.tissueSampleMetadata (optional): Metadata related to the tissue sample
    • tissuesSampleCollection.tissueSampleMetadata.anatomicalSiteFreeText (optional): Free text describing the anatomical site
    • tissuesSampleCollection.tissueSampleMetadata.anatomicalSiteOntologyCode (optional): Ontology code for the anatomical site, this code must match an ICD-0-3 format
    • tissuesSampleCollection.tissueSampleMetadata.anatomicalSiteOntologyDescription (optional): Ontology description for the anatomical site
    • tissuesSampleCollection.tissueSampleMetadata.creationDate (optional): Date when the tissue sample metadata was created
    • tissuesSampleCollection.tissueSampleMetadata.id (optional): ID of the tissue sample metadata
    • tissuesSampleCollection.tissueSampleMetadata.sampleContentDiagnosis (optional): Diagnosis related to the sample content
    • tissuesSampleCollection.tissueSampleMetadata.sampleDonor (optional): Information about the sample donor
    • tissuesSampleCollection.tissueSampleMetadata.sampleDonor.birthDate (optional): Date of birth of the sample donor
    • tissuesSampleCollection.tissueSampleMetadata.sampleDonor.dataCategories (optional): Data categories related to the sample donor
    • tissuesSampleCollection.tissueSampleMetadata.sampleDonor.id (optional): ID of the sample donor
    • tissuesSampleCollection.tissueSampleMetadata.sampleDonor.sex (optional): Sex of the sample donor
    • tissuesSampleCollection.tissueSampleMetadata.sampleType (optional): Type of the tissue sample
    • tissuesSampleCollection.tissueSampleMetadata.storageTemperature (optional): Storage temperature of the tissue sample
    • tissuesSampleCollection.tissueSampleMetadata.useRestrictions (optional): Restrictions on the use of the tissue sample

    Removed

    • coverage.physicalSampleAvailability
    • summary.publisher.publisherGatewayId
    • summary.publisher.publisherName
