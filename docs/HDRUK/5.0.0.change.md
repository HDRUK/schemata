## Changes from 4.1.0 -> 5.0.0

### Added

- **`accessibility.access.applicableLegislation`** *(optional)*: Legislation governing the access and use of this dataset (dcatap:applicableLegislation), e.g. 'UK GDPR', 'Health and Social Care (Safety and Quality) Act 2015'.
- **`accessibility.access.legalBasis`** *(optional)*: Legal basis under which personal data in this dataset is processed (dpv:hasLegalBasis). Reference the relevant legislation or DPV concept, e.g. 'GDPR Art.9(2)(j) - scientific research'.
- **`accessibility.access.personalData`** *(optional)*: Description of the categories of personal data held in the dataset (dpv:hasPersonalData). Reference DPV personal data categories or describe the types of identifiers and sensitive data present.
- **`context`** *(optional)*: URI of the JSON-LD context document that maps HDRUK field names to their DCAT, HealthDCAT-AP, and Dublin Core equivalents. When present, this document is directly consumable by a JSON-LD processor as a healthdcatap:HealthDataset.
- **`coverage.numberOfRecords`** *(optional)*: Total number of rows or records in the dataset (healthdcatap:numberOfRecords). May exceed numberOfUniqueIndividuals for longitudinal datasets.
- **`coverage.numberOfUniqueIndividuals`** *(optional)*: Count of unique individuals (patients, participants) represented in the dataset (healthdcatap:numberOfUniqueIndividuals).
- **`coverage.populationCoverage`** *(optional)*: Plain-text description of the population represented in the dataset (healthdcatap:populationCoverage). Include demographic scope, inclusion/exclusion criteria, and geographic focus where applicable.
- **`distributions`** *(optional)*: DCAT-compliant distribution records for this dataset. Each distribution represents a specific downloadable or accessible form of the data (dcat:distribution).
- **`distributions.accessService`** *(optional)*: Data service that provides access to this distribution (dcat:accessService).
- **`distributions.accessUrl`** *(optional)*: URL of a resource that gives access to the distribution (dcat:accessURL). May point to a data service or landing page.
- **`distributions.byteSize`** *(optional)*: Size of the distribution in bytes (dcat:byteSize).
- **`distributions.description`** *(optional)*: Human-readable description of this distribution (dct:description).
- **`distributions.downloadUrl`** *(optional)*: Direct URL to download the distribution file (dcat:downloadURL).
- **`distributions.format`** *(optional)*: File format label of the distribution, e.g. CSV, Parquet (dct:format).
- **`distributions.issued`** *(optional)*: Date this distribution was first published (dct:issued).
- **`distributions.licenseUrl`** *(optional)*: Licence URI for this specific distribution; overrides the dataset-level licence if provided (dct:license).
- **`distributions.mediaType`** *(optional)*: IANA media type of the distribution, e.g. text/csv, application/json (dcat:mediaType).
- **`distributions.modified`** *(optional)*: Date this distribution was last modified (dct:modified).
- **`distributions.title`** *(optional)*: Display name of this distribution (dct:title).
- **`id`** *(optional)*: URI uniquely identifying this dataset record (dcat:Dataset identifier).
- **`provenance.retentionPeriod`** *(optional)*: Period for which the dataset (or records within it) is retained (healthdcatap:retentionPeriod). Provide start and/or end dates to indicate when data will be deleted or archived.
- **`provenance.retentionPeriod.endDate`** *(optional)*: End of the data retention period.
- **`provenance.retentionPeriod.startDate`** *(optional)*: Start of the data retention period.
- **`qualityAnnotations`** *(optional)*: Quality annotation records documenting data quality scores, certifications, or assessments (dqv:QualityAnnotation).
- **`qualityAnnotations.annotationDate`** *(optional)*: Date when this quality annotation was recorded (prov:generatedAtTime).
- **`qualityAnnotations.annotationType`** *(optional)*: Category of quality annotation: 'duf_score' for a numeric quality score, or 'certification' for a formal certification.
- **`qualityAnnotations.certificationUrl`** *(optional)*: URL linking to the full certification or assessment report.
- **`qualityAnnotations.qualityDescription`** *(optional)*: Human-readable description of the quality annotation (skos:note).
- **`qualityAnnotations.qualityDimension`** *(optional)*: The quality dimension being measured, e.g. completeness, accuracy, timeliness (dqv:inDimension).
- **`qualityAnnotations.qualityValue`** *(optional)*: The score, grade, or pass/fail result for this quality annotation (dqv:value).
- **`summary.controlledKeywords`** *(optional)*: Curated subset of keywords drawn from a controlled vocabulary. Complements free-text keywords.
- **`summary.creator`** *(optional)*: Entity responsible for originally creating the dataset (dct:creator). May differ from the data custodian.
- **`summary.creator.gatewayId`** *(optional)*: HDR UK Gateway identifier for the creator organisation.
- **`summary.creator.name`** *(optional)*: Name of the person or organisation that created the dataset (foaf:name).
- **`summary.creator.orcidId`** *(optional)*: ORCID identifier URI, e.g. https://orcid.org/XXXX-XXXX-XXXX-XXXX.
- **`summary.creator.rorId`** *(optional)*: Research Organization Registry identifier URI, e.g. https://ror.org/XXXXXXXX.
- **`summary.landingPage`** *(optional)*: URL of a human-readable landing page for the dataset (dcat:landingPage).
- **`summary.licenseUrl`** *(optional)*: URI of the dataset-level licence (dct:license). Use a recognised licence URI such as https://creativecommons.org/licenses/by/4.0/.
- **`summary.shortTitle`** *(optional)*: Abbreviated or acronym title for the dataset, used in list/card views (dcterms:alternative).
- **`summary.theme`** *(optional)*: Array of controlled vocabulary concept URIs categorising the dataset by subject area (dcat:theme). Use EuroVoc or NHS Data Dictionary URIs where available.
- **`type`** *(optional)*: RDF type of this record. Defaults to healthdcatap:HealthDataset, which is a subclass of dcat:Dataset.
