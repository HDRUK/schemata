## Changes from 2.1.3 -> 2.2.0

### Added

- **`coverage.anthropometric`** *(optional)*: Height, Weight, Waist circumference, Hip circumference, Blood pressure
- **`coverage.biologicalsamples`** *(optional)*: Blood, Saliva, Urine, Other
- **`coverage.gender`** *(optional)*: Male, Female, Other
- **`coverage.lifestyle`** *(optional)*: Cohort lifestyle habits: Smoking, Physical activity, Dietary habits, Alcohol
- **`coverage.physical`** *(optional)*: Cardiovascular, Respiratory, Musculoskeletal, Hearing and Vision, Reproductive
- **`coverage.psychological`** *(optional)*: Mental health, Cognitive function
- **`coverage.socioeconomic`** *(optional)*: Occupation, Family circumstances, Housing, Education, Ethnic group, Martial status, Social support
- **`summary.datasetSubType`**: Placeholder for dataset sub-type
- **`summary.datasetType`**: Placeholder for dataset type"
- **`summary.populationSize`**: Summary population size of the cohort
- **`tissuesSampleCollection`** *(optional)*: Metadata collection for Tissue Samples datasets
- **`tissuesSampleCollection.collectionType`** *(optional)*: The type of the sample collection. Can be several values MIABIS-2.0-16
- **`tissuesSampleCollection.dataCategories`** *(optional)*: The type of data that is associated with the samples in the study. Can be several values MIABIS-2.0-13
- **`tissuesSampleCollection.materialType`** *(optional)*: The biospecimen saved from a biological entity for propagation e.g. testing, diagnostics, treatment or research purposes. Can be several values MIABIS-2.0-14
- **`tissuesSampleCollection.tissueSampleMetadata`** *(optional)*: Metadata related to the tissue sample
- **`tissuesSampleCollection.tissueSampleMetadata.AnatomicalSiteOntologyCode`** *(optional)*: Ontology code for the anatomical site, this code must match an ICD-0-3 format
- **`tissuesSampleCollection.tissueSampleMetadata.creationDate`** *(optional)*: Date when the tissue sample metadata was created

### Removed

- **`coverage.physicalSampleAvailability`**
