## Changes from 4.0.0 -> 4.1.0

- **Add** `accessibility.formatAndStandards.conformsTo` allowed values: `BNF`, `DDI`, `DCAT`
- **Add** `accessibility.usage.dataUsePermissions` (new section), containing:
  - `patientRecontact`: whether the people from whom the dataset is generated can be recontacted as part of a follow-up or new study (`Yes`/`No`, defaults to `No`)
- **Add** `accessibility.usage.duoCodes`: GA4GH Data Use Ontology (DUO) codes describing permitted/restricted uses of the dataset

All additions are optional and backwards compatible - no existing required fields, types, or allowed values changed.
