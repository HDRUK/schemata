## Changes from 4.0.0 -> 4.1.0

### Added

- **`accessibility.usage.dataUsePermissions`** *(optional)*: Permissions relating to how people and materials within this dataset may be used, beyond the general access and use conditions described elsewhere in this section.
- **`accessibility.usage.dataUsePermissions.patientRecontact`** *(optional)*: Indicates whether the people from whom the dataset is generated can be recontacted as part of a follow-up or new study.
- **`accessibility.usage.duoCodes`** *(optional)*: Machine-readable codes from the GA4GH Data Use Ontology describing the permitted or restricted uses of this dataset, for interoperability with other GA4GH-compliant systems.
