## Changes from 1.2 -> 2.0

### Added

- **`coverage.datasetCompleteness`** *(optional)*: The URL where a Researcher can learn more about the completeness of the dataset.
- **`coverage.followUp`** *(optional)*: If known, what is the typical time span that a patient appears in the dataset (follow up period)
- **`demographicFrequency`** *(optional)*: An object containing demographic frequency data categorised by age, ethnicity, and disease attributes.
- **`demographicFrequency.age`** *(optional)*: Array of age bins and their corresponding counts.
- **`demographicFrequency.age.bin`**: Age bin
- **`demographicFrequency.age.count`**: Age count
- **`demographicFrequency.disease`** *(optional)*: Array of diseases and their corresponding counts.
- **`demographicFrequency.disease.count`**: Disease count
- **`demographicFrequency.disease.diseaseCode`**: Disease code
- **`demographicFrequency.disease.diseaseCodeVocabulary`**: Disease code vocabulary
- **`demographicFrequency.ethnicity`** *(optional)*: Array of ethnicity bins and their corresponding counts.
- **`demographicFrequency.ethnicity.bin`**: Ethnicity bin
- **`demographicFrequency.ethnicity.count`**: Ethnicity count
- **`linkage.datasetLinkage.isDerivedFrom.pid`** *(optional)*: Persistent identifier of a dataset
- **`linkage.datasetLinkage.isDerivedFrom.title`** *(optional)*: Title of a dataset
- **`linkage.datasetLinkage.isDerivedFrom.url`** *(optional)*: Url of a dataset
- **`linkage.datasetLinkage.isMemberOf.pid`** *(optional)*: Persistent identifier of a dataset
- **`linkage.datasetLinkage.isMemberOf.title`** *(optional)*: Title of a dataset
- **`linkage.datasetLinkage.isMemberOf.url`** *(optional)*: Url of a dataset
- **`linkage.datasetLinkage.isPartOf.pid`** *(optional)*: Persistent identifier of a dataset
- **`linkage.datasetLinkage.isPartOf.title`** *(optional)*: Title of a dataset
- **`linkage.datasetLinkage.isPartOf.url`** *(optional)*: Url of a dataset
- **`linkage.datasetLinkage.linkedDatasets.pid`** *(optional)*: Persistent identifier of a dataset
- **`linkage.datasetLinkage.linkedDatasets.title`** *(optional)*: Title of a dataset
- **`linkage.datasetLinkage.linkedDatasets.url`** *(optional)*: Url of a dataset
- **`linkage.publicationAboutDataset`** *(optional)*: DOIs for publications which describe the dataset.
- **`linkage.publicationUsingDataset`** *(optional)*: DOIs for publications which use the dataset for analysis.
- **`omics`** *(optional)*: Omics
- **`omics.assay`** *(optional)*: The specific 'omics assay that generated the dataset.
- **`omics.platform`** *(optional)*: The specific technology or infrastructure used to perform the assay. If the omics platform used to create your dataset is not listed, please select other, a member of the gateway team will contact you to add an appropriate term(s) both to your record and to the metadata schema on your behalf.
- **`provenance.origin.imageContrast`** *(optional)*: Indicate whether usage of imaging contrast is captured within the dataset.
- **`summary.inPipeline`** *(optional)*: Indicate whether this dataset is currently available for Researchers to request access.

### Removed

- **`coverage.anthropometric`**
- **`coverage.biologicalsamples`**
- **`coverage.followup`**
- **`coverage.gender`**
- **`coverage.lifestyle`**
- **`coverage.physical`**
- **`coverage.psychological`**
- **`coverage.socioeconomic`**
