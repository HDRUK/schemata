## Changes from 2.0 -> 2.1

### Added

- **`datasetFilters`** *(optional)*: Categorization tags regarding cancer type, data type, and access.
- **`datasetFilters.category`**: Category
- **`datasetFilters.description`**: Description
- **`datasetFilters.id`**: Id
- **`datasetFilters.label`**: Label
- **`datasetFilters.primaryGroup`**: Primary group
- **`erd`** *(optional)*: Visual representation of data table relationships.
- **`erd.description`** *(optional)*: 
- **`erd.image`** *(optional)*: An image file.
- **`icons`** *(optional)*: Calculated categorization icons added during export.
- **`projectGrants`** *(optional)*: Associated Project Grants
- **`projectGrants.grantNumber`**: List of CRUK and any other grant numbers.
- **`projectGrants.leadResearchInstitute`**: Lead Research Institute
- **`projectGrants.leadResearcher`**: Lead Researcher
- **`projectGrants.pid`** *(optional)*: Persistent identifier of the study
- **`projectGrants.projectGrantEndDate`**: Current end date of project grant.
- **`projectGrants.projectGrantName`**: The Project Grant Title should be unique to the CRUK datahub. (Add your institute or name if necessary to disambiguate).
- **`projectGrants.projectGrantScope`** *(optional)*: data and biospecimens expected to result from the grant.
- **`projectGrants.projectGrantStartDate`**: Starting date of projectGrant grant.
- **`summary.funders`** *(optional)*: Comma-separated list of funders for this dataset.
