## Changes from 2.1 -> 3.0

### Added

- **`accessibility.access.applicableLegislation`** *(optional)*: Applicable legislation governing the dataset, e.g. GDPR, UK GDPR (dcatap:applicableLegislation).
- **`accessibility.access.legalBasis`** *(optional)*: Legal basis for processing personal data under this dataset (dpv:hasLegalBasis).
- **`accessibility.access.personalData`** *(optional)*: Type of personal data held in the dataset (dpv:hasPersonalData).
- **`accessibility.usage.dataUseRequirements`** *(optional)*: Please indicate fit here are any additional conditions set for use if any, multiple requirements may be provided. Please ensure that these restrictions are documented in access rights information.
- **`coverage.maxTypicalAge`** *(optional)*: Upper bound of typical participant age in whole years (healthdcatap:maxTypicalAge).
- **`coverage.minTypicalAge`** *(optional)*: Lower bound of typical participant age in whole years (healthdcatap:minTypicalAge).
- **`coverage.numberOfRecords`** *(optional)*: Total row/record count in the dataset (healthdcatap:numberOfRecords).
- **`coverage.numberOfUniqueIndividuals`** *(optional)*: Count of unique individuals in the dataset (healthdcatap:numberOfUniqueIndividuals).
- **`coverage.populationCoverage`** *(optional)*: Description of the population covered by the dataset (healthdcatap:populationCoverage).
- **`distributions`** *(optional)*: DCAT-compliant distribution records for this dataset (dcat:Distribution).
- **`distributions.accessService`** *(optional)*: Service providing access to this distribution (dcat:accessService).
- **`distributions.accessUrl`** *(optional)*: URL to access the distribution (dcat:accessURL).
- **`distributions.byteSize`** *(optional)*: Size of the distribution in bytes (dcat:byteSize).
- **`distributions.description`** *(optional)*: Human-readable description of the distribution (dct:description).
- **`distributions.downloadUrl`** *(optional)*: Direct download URL for the distribution (dcat:downloadURL).
- **`distributions.format`** *(optional)*: File format label of the distribution (dct:format).
- **`distributions.issued`** *(optional)*: Date the distribution was published (dct:issued).
- **`distributions.licenseUrl`** *(optional)*: Distribution-level licence URI; overrides the dataset-level licence (dct:license).
- **`distributions.mediaType`** *(optional)*: IANA media type of the distribution, e.g. text/csv (dcat:mediaType).
- **`distributions.modified`** *(optional)*: Date the distribution was last modified (dct:modified).
- **`distributions.title`** *(optional)*: Display name of the distribution (dct:title).
- **`provenance.retentionPeriod`** *(optional)*: Data retention period for the dataset (healthdcatap:retentionPeriod).
- **`provenance.retentionPeriod.endDate`** *(optional)*: End of the data retention period.
- **`provenance.retentionPeriod.startDate`** *(optional)*: Start of the data retention period.
- **`qualityAnnotations`** *(optional)*: Quality annotation records for this dataset (dqv:QualityAnnotation).
- **`qualityAnnotations.annotationDate`** *(optional)*: Date the annotation was recorded (prov:generatedAtTime).
- **`qualityAnnotations.annotationType`** *(optional)*: Type of quality evidence: duf_score for Data Utility Framework scores, certification for external certifications.
- **`qualityAnnotations.certificationUrl`** *(optional)*: Link to the certification document.
- **`qualityAnnotations.qualityDescription`** *(optional)*: Human-readable description of the annotation (skos:note).
- **`qualityAnnotations.qualityDimension`** *(optional)*: Quality dimension being assessed, e.g. completeness, accuracy (dqv:inDimension).
- **`qualityAnnotations.qualityValue`** *(optional)*: Score or grade value for this annotation (dqv:value).
- **`summary.creator`** *(optional)*: Entity responsible for creating the dataset (dct:creator).
- **`summary.creator.gatewayId`** *(optional)*: HDR UK Gateway internal identifier for the creator.
- **`summary.creator.name`** *(optional)*: Display name of the entity responsible for creating the dataset (foaf:name).
- **`summary.creator.orcidId`** *(optional)*: ORCID identifier for the creator individual.
- **`summary.creator.rorId`** *(optional)*: Research Organisation Registry identifier for the creator organisation.
- **`summary.landingPage`** *(optional)*: URL of a human-readable landing page for the dataset (dcat:landingPage).
- **`summary.licenseUrl`** *(optional)*: URI of the dataset-level licence (dct:license).
- **`summary.theme`** *(optional)*: Array of controlled vocabulary URIs categorising the dataset (dcat:theme).

### Removed

- **`accessibility.usage.dataUseRequirement`**
- **`coverage.typicalAgeRange`**

### Modified

- **`accessibility.formatAndStandards.formats`**: type `CommaSeparatedValues[{'anyOf': [{'pattern': '([^,]+)', 'type': 'string'}, {'type': 'null'}]}]|null` → `str`; is now a list
- **`accessibility.usage.dataUseLimitation`**: type `CommaSeparatedValues[{'anyOf': [{'pattern': '([^,]+)', 'type': 'string'}, {'type': 'null'}]}]|null` → `str`; is now a list
- **`coverage.datasetCompleteness`**: type `Url[{'anyOf': [{'format': 'uri', 'minLength': 1, 'type': 'string'}, {'type': 'null'}]}]|null` → `str|null`
